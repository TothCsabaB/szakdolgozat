# Szakdolgozat

## Téma: Ütközésvizsgálatot megvalósító módszerek hatékonyságának vizsgálata és optimalizálása

Feladat leírás:

A számítógépes grafikában és a végeselem módszeres szimulációk esetében nagyon fontos,
hogy a fizikai számítások minél gyorsabban, minél kisebb számítási erőforrással
végrehajthatóak legyenek. A szakdolgozat azt vizsgálja, hogy milyen módon minimalizálható
a számítások mennyisége. Ehhez áttekintésre kerülnek a szakirodalomban és alkalmazásokban
fellelhető elterjedt megoldások. A dolgozat példákon, saját fejlesztésű szimulációkon
keresztül bemutatja, hogy hogyan használhatók a gépi tanulási módszerek a számítások
hatékonyabbá tételében. A számításokhoz, a megjelenítéshez és a szimulációkhoz az
alkalmazás C programozási nyelven (C23 szabvány szerint) készül OpenGL grafikus
függvénykönyvtár felhasználásával. A gépi tanulási módszerek vizsgálata, az eredmények
kiértékelése Python programozási nyelv és a hozzá tartozó függvénykönyvtárak segítségével
történik.
